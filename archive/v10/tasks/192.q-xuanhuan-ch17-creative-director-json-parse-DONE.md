## 根因

xuanhuan clean Ch100 rebuild 在 Ch17 失败，直接错误为：

```text
CreativeDirector LLM call failed: LLM 返回内容无法解析为 JSON: Expecting ',' delimiter
```

冻结日志显示 DeepSeek v4 flash 在 `creative_intent` 字符串内部输出了未转义英文引号：

```json
"creative_intent": "......而不是觉得"又过了一关"。"
```

CreativeDirector 使用本地 `_parse_llm_response()`，仅做 `_extract_json()` + `json.loads()`，没有复用 `songyan.llm.parsing.parse_llm_response()` 的 `json_repair` fallback；通用 parser 已能修复该类未转义内部引号。

---

## 修复

- `src/songyan/agents/creative_director/_brief_builder.py`
  - `_parse_llm_response()` 改为复用通用 `parse_llm_response()`。
  - 保持返回类型和异常契约不变，仍返回 `dict[str, Any]`，解析失败仍抛 `LLMResponseParseError`。
- `tests/test_creative_director.py`
  - 新增 `test_repairs_unescaped_inner_quotes_from_structured_brief()`，覆盖 CreativeDirector structured brief 字符串内部未转义英文引号。
