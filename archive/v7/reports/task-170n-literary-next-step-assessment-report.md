路径 B 的轻量策略（170h→170i→170j→170k→170l）连续五步均未达标，收益递减/劣化。本报告评估三条候选方向。

## 三条候选方向

### A. 路径 B 升级（更激进结构性改写）

**核心假设**：约束不够硬；给 Writer/CreativeDirector 增加不可绕过的硬节拍和配额，可强制 voice/exposition 达标。

**子策略**：
1. 人类角色台词硬配额（单章字数/单句信息密度上限）。
2. 非人实体信息投递硬限制（单句高概念词上限、单章直接揭示句数上限）。
3. 对白-动作交替硬节拍（任何说明性对白后必须跟动作/冲突/失败反应）。
4. 认知冲突前置模板（每章至少 2 处“主角误判→对立判断→付出代价→修正认知”节拍）。
5. 声纹同质化扣 quality gate 分，触发 rewrite。

**工程量**：8–12 文件，15–25 单测，2–3 轮小样本验证。
**LLM 成本增量**：高。
**风险**：可能越界 V7“不做全自动 LLM 改写闭环”纪律；模型可能换壳（对白→独白/叙事解释）；可能拖慢生成、引入新的 meta_tag/字数异常。
**回退触发**：Ch29–Ch32 小样本 voice/exposition 仍 <3.0。

### B. AI 腔后处理（反模板化 rewrite 规则）

**核心假设**：模型输出本身带 AI 腔和说明性，单靠 prompt 不够，需在 RevisionHandler 层硬性后处理。

**子策略**：
1. 说明性对白压缩：RevisionHandler 检测到 `info_delivery_dialogue` / `direct_revelation_monologue` 时压缩或拆成动作+短对白。
2. 反模板化改写：针对高频 AI 腔句式做规则化替换。
3. 声纹同质化拆分：对 `human_voice_homogeneity` 命中对白强制插入语气词、打断、口癖。
4. 自动 few-shot 替换：从人工审定“好对白”样本库抽取替换模板。

**工程量**：4–6 文件，10–15 单测，1 轮小样本验证。
**LLM 成本增量**：中（只在 revision 命中时）。
**风险**：局部改写可能破坏上下文连贯性；样本库不足时质量不稳定；仍可能换壳为独白。
**回退触发**：后处理样本无法稳定提升 voice/exposition。

### C. 目标降级（诚实降级文学目标）

**核心假设**：当前 deepseek-chat + 当前 prompt 工程深度，在 V7 MVP 边界内难以让 voice/exposition 同时 ≥3.0。

**子策略**：
1. 文学目标从“voice/exposition ≥3.0”调整为：
   - pacing/concept 不回退（≥3.0）；
   - voice/exposition ≥2.0 且不继续塌陷；
   - T9 0/0、exposition_carrier 高置信 ≤3；
   - 每 25 章人工抽读，连续 2 窗 voice/exposition <2.5 触发 halt。
2. 启动 Task 171 Ch200 长跑，文学修复改为“长跑中持续抽读+定点修复”。
3. 预留 171p/172p/173p 撞墙修复占位，可尝试方向 B 的小范围 patch。

**工程量**：2–4 文件，5–8 单测，无额外 LLM 成本。
**LLM 成本增量**：低。
**风险**：文学债可能随长跑放大；需要严格的人工抽读纪律。
**回退触发**：Ch200 长跑中 voice/exposition 继续塌陷。

## 推荐与决策建议

**songyan-agent 推荐**：
1. **首选方向 C（目标降级）**：立即解除 Ch200 冻结，把文学修复从放行前置门转为长跑中抽读+定点修复。这与 V7 MVP 边界完全兼容，且能把阶段 Z 重新推进。
2. **同步准备方向 B 的最小可行版本**：作为 171p/172p/173p 撞墙修复工具，不阻塞 Ch200 长跑启动。
3. **方向 A 作为备选**：只有在方向 C 长跑中 voice/exposition 继续塌陷时才投入。

**理由**：
- 路径 B 轻量策略五步验证已到顶，继续追加同层级约束的边际收益极低。
- 方向 A 工程量大、越界风险高、模型换壳可能性大。
- 方向 B 适合作为定点工具，但样本库和质量稳定性不足以单独支撑放行前置门。
- 方向 C 可立即推进阶段 Z，同时保留后续修复空间。
