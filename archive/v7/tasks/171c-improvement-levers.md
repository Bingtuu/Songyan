## 任务边界

Task 171c 解决旧框架的**单一仓鼠轮**错误（框架文档 E5）：路径 B 五步只有"拧 prompt"一根杠杆，且无退出判据，连续递减/劣化还在继续。本任务把提质变成**多杠杆组合 + 假设检验 + 退出判据**：每根杠杆是一个可证伪假设，在 171a 可信量具 + 171b 代表样本上做受控 A/B，边际增益不达标即停、换下一根。

**前置铁律**：171a 未达标出口（voice/exposition 量具不可信）前，**禁止启动本任务的对应维度**（框架 §8 B 组纪律）。prompt 工程（170h–170l）已封存，不作为本任务杠杆。

## 候选杠杆（每根 = 一个假设 + 退出判据）

| 杠杆 | 假设 | 退出判据 |
|---|---|---|
| 确定性后处理 rewrite | RevisionHandler 局部拆"说明性对白/独白" → 动作+短对白，能提 exposition 融合度 | 代表样本上边际增益 < 阈值即停 |
| 好样本 few-shot（人审库） | 给模型看"本系统人工审定的好对白"，比抽象约束更有效 | 同上 |
| 解码参数（temperature/采样） | 声纹同质可能部分源于低多样性解码 | 低成本先试；无效即停 |
| **换模型** | deepseek-chat 可能是当前 prompt 深度下的天花板 | 用同一代表样本 + 可信量具横比一次，有结论即可（不要求必须提升） |
| 人工定点抽读修复 | 长跑中兜底，经 171p/172p/173p 注入 | 常驻，不设退出 |

**执行规则**：每根杠杆独立受控 A/B；**连续 2 次非提升即停该杠杆、换下一根**（防止重演路径 B 的递减迭代）。

## 验收标准（对应框架 §8 R2 + §8.5）
- 每根被验证的杠杆都有：假设陈述、在 171a 可信量具 + 171b 代表样本上的受控 A/B 结果、边际增益判定、是否继续/退出的结论。
- **"换模型"杠杆至少被评估过一次并有横比结论**（框架 §8.4 明确：不要求它必须提升，只要求有结论）。
- 工程：`ruff`/pytest 通过；不改已冻结门禁；成熟杠杆的注入通道对接 171p/172p/173p。

## 出口纪律（框架 §8.5）
- 若某杠杆稳定提升 → 固化为长跑定点工具，经 `NNNp` 注入。
- 若**所有杠杆（含换模型）均无边际增益** → 结论"当前技术栈下文学上限已达"，Tier 3 关闭迭代、转长期研究；**不回退到用文学阻塞 Ch200**。
