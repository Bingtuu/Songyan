## 已知限制

- **urban Ch199/200 使用了 fallback model**：因首选模型多次空响应，最后两章由 `deepseek/deepseek-chat` 完成。样本可作为 urban Ch200 PASS 终点，但不应记为首选模型的 clean sample。
- **数据缺口**：xuanhuan / wuxia 只记录了终点五门数值（无 Ch125-175 分点值）；三非 sci-fi 体裁未记录 CED 字数与修订轮数统计。
- **Ch200 baseline JSON 未随包分发**：随 pip 包分发的 sci-fi baseline（`scifi_ch100_v8_freeze`）覆盖 Ch25-100；Ch125-200 四点为内部归档记录，上表即其完整公开内容。
