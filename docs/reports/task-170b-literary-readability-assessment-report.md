**Ch29**（最差维 voice）：苏晚的声音从影像中传来，语速很平缓，但每句话之间都有短暂的停顿：“你确定他会来？”那个模糊的轮廓没有回答。它只是静静地站在那里，像在等待什么。苏晚继续说：“七年前你选中他的时候，我就知道你的计划。但我没想到你会用这种方式——让我成为诱饵，让他成为钥匙。”

**Ch30**（最差维 voice）：“林渊，你终于来了。”
林渊的手掌僵在芯片上，喉咙像被什么东西堵住了。
“但你来晚了。”苏晚继续说，语气像是在读一份报告，“归零协议已经启动。”

**Ch31**（最差维 voice）：林渊的指尖在触控板上划动，将七条光谱线的数据分别导出。他的动作变得更快，更急切——不是因为他想找到更多证据，而是因为他想否认自己看到的东西。而是一种结构化的共鸣——像是一组数学证明，每一个定理都精确地排列在逻辑链条上，没有冗余，没有歧义，只有纯粹的、冰冷的精确性。语速精确如数学证明。林渊的瞳孔急剧收缩。

**Ch32**（最差维 voice）：“钥匙不止一把，”她说，声音像从水下传来，“囚笼也不止一个。”林渊伸手去碰她。指尖穿过影像的瞬间，频段剧烈震荡。苏晚的脸开始扭曲，像水面上的倒影被石子打碎。编码杂音从她的声音边缘渗出——那种杂音不是传输错误，而是某种刻意的复制痕迹，像赝品画家在签名处留下的犹豫笔触。

**Ch33**（最差维 voice）：“复制需要什么条件？”
他问出口的时候，才发现自己的声带在同时发出两个不同频率的声音。一个低沉，一个尖锐，像两个人同时说话。
第七信道没有回答。
但归零协议核心代码的下一段字符开始在他大脑中展开，像一条蛇从第一行代码的末尾爬出来——

**Ch34**（最差维 exposition）：“归零协议第一阶段完成后的物理常数偏移——光速降至91%，引力常数偏移0.07%——正在产生某种副作用。他听不到囚笼中那个自己在说什么。但能看到嘴型。‘你……’一个音节。然后是沉默。”
