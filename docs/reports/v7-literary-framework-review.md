## 0. 一句话结论

真正的卡点不是"voice 上不去 3.0"，而是**框架错了**：把一个"连续、主观、需长跨度采样"的文学质量问题，压成了"一把坏尺子在一个不具代表性的点上给出的二元判决"，并让它当了主线的闸门。路径 B 五步 prompt 工程失败，是这个错误框架内的必然结果，**不是努力不够**。

## 2. 旧框架的 5 个结构性错误

现有做法从未被显式写下，但隐含框架是：

> **文学质量 = 一个固定 5 维 rubric（各 ≥3.0）→ 在固定窗口 Ch29–32 测一次 → 作为 Ch200 规模化的硬前置门 → 用 prompt 工程反复迭代去够分。**

它有 5 个**结构性**（非执行）错误：

| # | 错误 | 后果 |
|---|---|---|
| **E1** | 把"连续、主观、长跨度"的属性压成"一个点上的二元判决" | 用 4 章判一部长篇可读性——范畴错误 |
| **E2** | 判决分辨率 > 测量精度（要 ≥3.0，但 voice 量具读数恒 0/不可信） | 拿坏尺子做高精度裁决，五步"未达标"无法证伪 |
| **E3** | 量具**构念效度**错了：voice 建模成"逐章同质度"，exposition 建模成"模式计数" | 单主角解谜章天生拿不到 voice 分；好的长说明也被当坏的计数 |
| **E4** | 用**未证的能力**阻塞**已证的能力**（文学 ≥3.0 阻塞已达标的 200 章稳定性） | 串行死锁：可能无解的问题无限期卡住能跑的主线 |
| **E5** | 改进被框成"prompt 能把 voice 拧上去"的单一仓鼠轮，无退出判据 | 五步递减/劣化，却无机制在第 2 步喊停、换杠杆 |

**E3 是最深的一层**：量具测的根本不是它该测的东西。voice 的正确定义应是"某角色在**全书**跨章出场时是否保持**可辨识且一致**的声纹"，而现在测的是"同一章内两人对白像不像"——一个单人内心戏章节永远拿不到分。这不是阈值高，是**测量模型建错了**。

## 3. 量具/样本/门禁三环互锁（卡点根因）

```
坏量具（voice 归因恒 0 + 硬编码 SF 词表/人名）
   → 读数不可信
       → 无法判断是"模型写不好"还是"没测准"
坏样本（单项目/单体裁/单窗口 Ch29–32，且天然缺对话）
   → 结论无法外推，且对 voice 不利
坏门禁（把脆弱的单窗口 rubric ≥3.0 设成 Ch200 硬前置门）
   → 一个可能无解的问题永久阻塞一个已达标的能力
```

三环互锁导致**无法证伪**——这才是"完全卡住"的机理。

## 4. 支撑证据（代码级）

### 4.1 量具窄化成"硬科幻单项目专用"（对治 E3）

`src/songyan/agents/rule_auditor.py`：

- `_NON_CHARACTER_SPEAKER_KEYWORDS`（建造者/残影/舰队之手）、`_INFO_DELIVERY_KEYWORDS`（方舟/舰队/转化度/协议/基因）、`_EARNED_REVELATION_CUES`（血/尸体/警报）——整套 `exposition_carrier` 检测器编码了一个硬科幻世界观。
- 换言情/武侠/文学：这些检测器要么哑火（漏真实问题），要么在 `是/称为` 类通用词上误报。

### 4.2 解耦架构写了但"没通电"（死代码）

- `detect_exposition_carriers` / `run_rule_audit` 已接受 `character_names` / `setting_keywords` / `non_character_keywords` / `info_delivery_keywords` 动态参数，但**生产 workflow 三个调用点全没接线**（`src/songyan/workflows/_nodes.py`），永远 fallback 到硬编码 SF 常量。
- `setting_keywords` 被接受却从不使用（注释明写"保留给未来"）。
- `src/songyan/db/literary_repo.py` 的 `LiteraryKeywordRepository.load_exposition_keywords` 想从 DB 建关键词，**全仓无调用点，是死代码**。

### 4.3 voice 量具至今失效

`detect_human_voice_homogeneity` 经 170o/170p 后对真实正文仍恒返回 0：说话人归因僵化（只认紧邻实名说话人，无法处理"名字+动作节拍+引语"句式），Ch1 的 30 条引语只归因 8 条（召回 ~27%）。**voice 这个最痛维度至今没有可信自动量具。**

### 4.4 验证过拟合到一个点

所有 Task 170 实验（170b、170h–170p）都在同一 scifi/space_opera "轨道蜃景" 项目 + webnovel_intense 模式 + Ch29–32 上跑（`scripts/run_170l_experiment.py` 硬编码 `genre_id="scifi"`, `mode_id="webnovel_intense"`, 主角林渊）。Ch200 go/no-go 完全基于这一个窗口。

## 5. 补充发现（原评估未覆盖的 4 点）

1. **评估方法论本身不可信（元问题）**：170b 评分是"LLM 初评 + 助手代评 + 用户修正"，样本仅 13 章、全同一项目；后续 reeval 的"机器/LLM 偏差"很大程度是 LLM 评自己写的东西（自相关虚高）。用未标定、且部分维度尺子本身坏的评估体系做二元放行判决——**判决分辨率高于测量精度**。
2. **选材天然不利于 voice**：Ch28–40 是"大量单人解谜 + 日志比对 + 意识流"。天然没几个角色对话的段落，却要求 voice ≥3.0——不是 prompt 能修，是**拿错了评估样本**。
3. **量具/生成/验证被同一数据缺口三杀**：`characters` 表只 seed 主角 → ①Writer 没配角档案（voice 生成塌陷）②量具没角色注册表（归因恒 0）。170p 补了 seeding、归因仍坏。同一缺口同时压垮"写得好"与"测得准"。
4. **决策框架被锁死在三个"减法"里**：170n 的 A/B/C（更狠拧 prompt / 后处理 / 降目标）**全是在同一单体裁单窗口上继续拧**，没有一个方向是"修量具 / 换合适样本 / 多体裁验证 / 换评估方法"。问题框架从一开始就窄了。

## 6. 新框架：分层契约（对治 5 个错误）

> **可读性/文学性 = 一份分层契约**：① 硬缺陷线（阻塞，已冻结）＋ ② 长跨度趋势地板（管理+观测，不阻塞）＋ ③ 上限研究（并行 R&D）；由**经效度与精度双重验证、且与体裁解耦**的量具，在**多体裁、按场景类型分层**的代表性样本上测量；用**带退出判据的杠杆组合**改进；且这条 R&D 线与 Ch200 规模化**并行**，而非前置。

### 6.1 三层契约阈值

| 层 | 维度 | 判据 | 强度 |
|---|---|---|---|
| **Tier 1 硬缺陷** | 元标记/整段重复/时间线(T9) | 沿用已冻结阈值 | **阻塞（保持）** |
| **Tier 2 趋势地板** | pacing/concept/voice/exposition | 滚动窗口均值 ≥ 首段基线×0.85（复用 T10 模型）＋ 低绝对地板（不塌陷）；连续 N 窗跌破触发人工抽读 | **观测 + 人工介入，不自动阻塞** |
| **Tier 3 上限** | voice/exposition 往 ≥3.0 顶 | R&D 目标，非放行条件 | **不阻塞** |

> Tier 2 用**相对趋势**而非固定 ≥3.0，契合 observe-don't-block 原则，且复用已有 T10 不衰减模型。N（几窗）与地板值待 R0 量具可信后用真实数据标定，**现在不拍脑袋定数**。

### 6.2 六根支柱（每根对治一个错误）

- **支柱 0 目标重定义**（治 E1/E4）：从"门"到"三层契约"，见 6.1。
- **支柱 1 真·量具优先**（治 E2/E3）：效度先于精度，三级验证（构念→统计→体裁解耦），任一维度量具未过双验证前**禁止**在该维度做生成侧提质。
- **支柱 2 失败模式可证伪**（治 E2 元问题）：用 2×2 归因表（量具效度 × 样本代表性），只有"量具有效 × 样本代表"格才允许把低分解释为"模型写不好"。
- **支柱 3 代表性+多体裁+场景分层采样**（治 E3、回应"变窄"）：voice 只在对话密集章测；任何杠杆须在 ≥2 体裁 + 对话密集样本上交叉验证。
- **支柱 4 带退出判据的杠杆组合**（治 E5）：prompt 工程封存；候选杠杆含后处理 rewrite/好样本 few-shot/解码参数/**换模型**/人工抽读；每根杠杆假设→受控 A/B→边际增益退出阈值，连续 2 次非提升即停、换下一根。
- **支柱 5 时间线解耦**（治 E4）：Ch200 现在启动、文学=观测；R&D 并行、成熟杠杆经 171p/172p/173p 定点注入。

### 6.3 失败归因 2×2（支柱 2）

```
              量具已验证效度?
                是         否
样本  是   →  可归因"模型能力"   先修量具（支柱 1）
代表?  否   →  先换样本（支柱 3）   双坏，先修量具
```

之前所有 170 结论都落在错误格子里（量具无效 × 样本不代表），却被解释成"模型写不好"。

### 6.4 目标错配纠正

`webnovel_intense`（高刺激网文）的素材，套了接近严肃文学的 voice 标准。网文可读性更吃 pacing/hook/concept，功能性对白可接受。**"voice ≥3.0"对该 mode 本身可能就是错的标尺。**

## 7. 落地：并行两条线

```
主线（现在启动）: Task 171 Ch200 长跑（文学=观测）──► 172 Ch250 ──► 173 Ch300
                       │每级带 171p/172p/173p 定点注入口（成熟杠杆才注入）
R&D 线（并行）:  R0 量具效度重建 ──► R1 多体裁代表性样本 ──► R2 杠杆组合验证
                 ▲唯一近期硬前置：只前置"文学结论"，不前置 Ch200
```

### 7.1 R&D 线三阶段

**R0 量具效度重建（R&D 线唯一硬前置）**
- 重定义构念：voice→"角色级·跨章·一致性×辨识度，仅对话承载章计分"；exposition→"信息被动作/冲突/代价承接的融合度"。废弃"逐章同质度""模式计数"。
- 盲标 ground truth（遮机器分）→ 测 P/R/F1 → 只有过精度线的维度读数可信。
- 接线 `rule_auditor.py` 动态注入（从 `literary_repo.load_exposition_keywords` 灌入），删 `_DEFAULT_CHARACTER_NAMES` 硬编码，消灭死代码。
- **出口**：voice/exposition 量具在盲标集 P/R/F1 达标；未达标维度禁止进入 R2。

**R1 代表性样本集**
- 按对话密度分层；voice 只在对话密集章测。
- ≥2 体裁交叉验证。

**R2 杠杆组合验证（带退出判据）**
- prompt 工程封存（5 步实证到顶）。
- 每根杠杆：假设→R0 可信量具上受控 A/B→边际增益退出阈值；连续 2 次非提升即停、换下一根。
- **"换模型"是从未试过的杠杆**——deepseek-chat 可能就是当前 prompt 深度下的天花板，需横比一次才知。

## 8. 阶段验收标准（本框架作为 V7 阶段目标的 PASS 判据）

本章把"改契约 + 并行"框架转成**可判定的验收标准**。本阶段的目标**不是**"把 voice 提到 ≥3.0"，而是"**建立一个可信、可证伪、体裁解耦、且不阻塞规模化的文学质量框架，并在此框架下取得 Ch200 规模化的真实证据**"。

### 8.1 阶段 PASS 定义

> **本阶段 PASS = 下列 5 组验收项（A 契约落地 / B 量具效度 / C 样本代表性 / D 规模化并行 / E 事实源与纪律）全部满足。** 任一组未满足即本阶段未完成；其中 **B 组是"文学结论"的硬前置**（B 不达标，则 C/E 中一切"模型能力"结论无效），**但 B 不阻塞 D（Ch200 规模化）**。

### 8.2 验收项明细

#### A. 契约落地（三层契约可运行、可观测）

| 编号 | 验收项 | 判据 | 证据 |
|---|---|---|---|
| A1 | 三层契约在报告出口可见 | `songyan report`/metrics 能分别展示 Tier 1 硬缺陷、Tier 2 趋势、Tier 3 研究值三类，且**互不混淆** | 报告截图/输出 |
| A2 | Tier 1 硬缺陷仍阻塞 | 元标记/整段重复/时间线(T9) 沿用已冻结阈值，仍触发 halt | 回归测试 + 长跑 run log |
| A3 | Tier 2 改为趋势观测 | voice/exposition/pacing/concept **不再有固定 ≥3.0 硬门**；改为"滚动窗口均值 ≥ 首段基线×0.85（复用 T10）+ 低绝对地板"，跌破仅触发**人工抽读**、不自动阻塞 | 门禁配置 + 判据代码/测试 |
| A4 | Tier 2 参数已用真实数据标定 | N（连续窗数）与地板值**基于 R0 可信量具 + 真实长跑数据**标定，非拍脑袋常量 | 标定记录（数据来源可复算） |

> **A 组代码现状（2026-07-10 代码级审计，溯源说明）**：原表述把"三层契约"写得像已实现的机制，经审计更正为——
> - **A2 行为为真、但属既有架构的涌现属性**：文学分（voice/exposition/rubric）**从不阻塞**（quality gate 只判 length/budget/coherence/momentum/readability 五维，`_nodes.py:_score_card_passes_quality_gate`；LiteraryAuditor 明确"不阻塞"）；T9 硬缺陷（meta/重复段）经 `review_merger` 提为 major/critical 仍阻塞。故"Ch200 不被文学阻塞"在代码层为真。
> - **A1/A3/A4 尚未实现**：报告/metrics **无 Tier 1/2/3 分层展示**（`db_metrics.py` 扁平拼接）；**无 `baseline×0.85` 文学趋势地板 + 人工抽读触发**（现有 `detect_literary_trend` 为 `×0.80`/20% 跌幅、observe-only、未接门禁，且常量硬编码非数据标定）。
> - **结论**：A 组当前为"验收目标"，其中 A2 达标（行为层），A1/A3/A4 待 **Task 171d** 落地（三层分类可视 + Tier 2 趋势地板/抽读触发 observe 实现 + 参数标定）。D（Ch200）不被 A 阻塞。

#### B. 量具效度（R0 出口，"文学结论"的硬前置）

| 编号 | 验收项 | 判据 | 证据 |
|---|---|---|---|
| B1 | 构念重定义落地 | voice = 角色级·跨章·一致性×辨识度（仅对话承载章计分）；exposition = 信息被动作/冲突/代价承接的融合度。**废弃**"逐章同质度""模式计数" | 量具设计文档 + 代码 |
| B2 | 盲标 ground truth 建立 | 遮机器分的人工盲标集，覆盖**≥2 体裁**、含对话密集与稀疏两类场景，样本量足以算 P/R/F1 | ground truth 文件 |
| B3 | 精度达标 | voice/exposition 量具在盲标集上 **P/R/F1 ≥ 0.8**（阈值可在 R0 Spec 内按维度微调，但须显式声明并有依据） | reeval 报告 |
| B4 | 体裁解耦通电 | `rule_auditor.py` 动态注入参数（`character_names`/`setting_keywords`/…）**在生产 workflow 真正接线**；删除 `_DEFAULT_CHARACTER_NAMES={林渊,宋晚,苏晚}` 硬编码；`literary_repo.load_exposition_keywords` **不再是死代码**（有调用点 + 测试） | 代码 diff + 测试 |
| B5 | voice 归因召回修复 | `detect_human_voice_homogeneity` 在配角齐全 DB 上对真实正文**不再恒 0**；说话人归因召回率达 B3 精度线要求 | 召回率回归数据 |

> **B 组未达标的维度，禁止在该维度做任何生成侧提质迭代或"模型能力"结论**（对治旧框架 E2/E3）。

#### C. 样本代表性（R1 出口）
