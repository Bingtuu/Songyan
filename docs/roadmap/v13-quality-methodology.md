> **阶段**: 质量方法论公开化
> **定位**: V13 是差异化资产建设阶段，目标是把 Songyan 独有的"可量化质量门"从内部纪律变成公开、可复现的方法论资产。不新增任何生成能力。
> **当前口径**: V11 已完成开源可用化收尾（Task 208-215），V12 启动校准进行中（Task 224/225 待闭环）。V13 与 V12 无代码依赖，可并行规划，但发布动作（baseline 公开）建议在 V11 正式 release tag 之后执行。
> **状态**: 进行中。Task 226 审计 DONE（报告 `docs/reports/226-v13-methodology-disclosure-audit.md`），Task 227 口径公开文档 DONE（`docs/quality-gates.md`），Task 228 baseline 脱敏公开 DONE（`docs/baseline-results.md`），当前任务为 Task 229 口径复现命令链。

## 背景结论

2026-09 同类项目调研（GitHub API 实时数据 + 2026-08 行业全景调研）结论：

- 头部同类 InkOS（~8.8k star，9-Agent 管线 + 真相文件）、ainovel-cli（~1.9k star，确定性 Engine + Worker）在功能广度上已占住心智，Songyan 不应在"功能全"上追赶。
- **没有同类项目拥有公开、可复现的质量度量口径**。InkOS 有 20+ 维审计但无量化阈值；NovelForge 靠 Schema 防错但无质量度量。CED / T9 / 五门 + 4 体裁 200 章冻结 baseline 是 Songyan 独有的差异化资产。
- 行业共识是"尚无项目能稳定全自动写出合格网文，天花板由基座模型决定"。在这个共识下，"能度量错误率"比"能生成"更稀缺。

关键判断：竞品可以抄功能，抄不走 baseline 数据和口径纪律。V13 的目标是把这项资产公开化。

相关内部依据：`docs/reports/217-project-overall-review.md` 确认 CED 只统计 consistency-only/merged/source/正文证据、T9 硬红线、五门 acceptance 口径全部真实落地。

## V13 硬边界

- 不新增核心 Agent / Workflow 节点。
- 不改变 CED / T9 / 五门的现有口径、阈值或 hard gate 语义。
- 不把 Task 197-206 的 report-only / spike 信号接入 prompt、CED 或 hard gate。
- 公开的 baseline 结果不含书稿正文、API key、绝对路径或任何未脱敏日志。
- 不动 `evals/` 的统计逻辑本身；允许新增的是文档、复现命令链和只读导出工具。
- SQLite 仍是唯一长期事实源。
- V11 正式 release tag 未完成前，V13 的对外公开动作（baseline 发布）不执行。

允许的改动：

- 新增 `docs/` 下的方法论文档。

- 对 baseline 数据做脱敏摘要导出。
- 更新 README / docs/INDEX.md 的导航。

## 公开范围与脱敏边界

| 可公开 | 不可公开 |
|--------|----------|
| CED / T9 / 五门的口径定义与阈值来源 | 任何书稿正文片段 |
| baseline 的聚合数值（错误率、通过/失败计数、分布） | run log 正文、prompt 全文 |
| 复现命令链与示例输出结构 | API key、绝对路径、机器名 |
| 口径的版本历史（何时冻结、何时调整） | 未脱敏的 bundle 内容 |

脱敏规则复用 Task 213 run bundle 的既有脱敏集合，不另造一套。
