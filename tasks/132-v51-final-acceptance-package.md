## 2. V5.1 目标定义（Brainstorming）

V5.1 不是新增大功能，而是 V5.0 之后的**质量收口与可观测性增强**。目标可定义为：

### 目标 A：Prompt 质量改善
- Writer / CreativeDirector / RuleAuditor 的 prompt 质量清理。
- 解决机械场景标题、元标记泄漏、短段落碎片化。

### 目标 B：测试矩阵补齐
- 单元、集成、E2E、压力四层测试覆盖关键路径。
- 为后续改动提供不回归的基线。

### 目标 C：硬门禁可配置
- 实现 ContextEmergency / health_low 候选硬门禁。
- 阈值调优到小窗口 0 误触发。
- 默认仍保持 observe，但用户可显式启用 enforce。

### 目标 D：文档一致性
- 消除规划稿与 DONE 文档并存的状态混乱。
- 索引文档指向最终事实。
