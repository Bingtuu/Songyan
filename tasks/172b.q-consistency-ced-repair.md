## 1. 现象

172b.p 修复后，xuanhuan 顺利推进到 Ch93，budget / overdue / health / completeness 均保持 PASS，但 CED 在终段持续超线：

| Ch92 | 10.66 | 9.24 | 10.63 | FAIL |

Ch100 的冻结 sci-fi ceiling = `9.1328 × 1.15 ≈ 10.50`。Ch93 当前值 10.76，剩余 7 章若平均 3000 字/章，新增 evidence issues 总量必须 ≤136（约 19.4/章）才可能自然摊薄；而最近热点：

| chapter | evidence issues（当前 vdim all reports） |
|---:|---:|
| Ch89 | 58 |
| Ch90 | 65 |
| Ch92 | 38 |
| Ch93 | 74 |

结论：按当前趋势，直接跑到 Ch100 大概率 CED FAIL。

## 2. 量具问题（必须先修）

诊断脚本：

- `.tmp/diagnose_ced_hotspots.py`
- `.tmp/ced_consistency_filter_probe.py`
- `.tmp/ced_merged_only_probe.py`
- `.tmp/ced_parent_merged_probe.py`

发现当前 `.tmp/vdim_compare.py` 的 CED numerator 过宽：

1. **把文学 craft issue 计入 CED**  
   Ch65/66/89/90/93 热点主因是 `show_dont_tell`、`narrative_pacing`、`dialogue_subtext`、`description_sensory` 等。它们是文学质量/写法问题，不是 Consistency Error Density。V8-README 对 Q 维度定义的是“一致性错误密度 CED”，文学 observe/文学质量不作为阻塞门。

2. **把 `llm` 与 `merged` 同时计数，存在双重计数**  
   `review_merger` 的 `merged` report 已包含 LLM issues；当前 vdim 直接遍历所有 `review_reports`，导致同一问题在 `llm` 和 `merged` 中被重复计入。sci-fi 与 xuanhuan 都受影响，但 xuanhuan 多轮修订更多，放大了误差。

3. **accepted 版本本身没有 review report**  
   accept 会创建新的 `chapter_versions(version_type='accepted')`，审查报告挂在其 `parent_version_id` 源版本上。直接 accepted-only 统计会得到 0，不能作为量具。

## 3. 真实 consistency 风险

即便过滤文学 craft 并只看 consistency 类别，xuanhuan 仍高于 sci-fi：

| 口径 | xuanhuan @Ch93 | sci-fi @Ch100 | ceiling（×1.15） | verdict |
|---|---:|---:|---:|---|
| all reports + consistency only | 3.33 | 2.78 | 3.19 | FAIL |
| merged only + consistency only | 1.72 | 1.37 | 1.57 | FAIL |

主要类别：

| category | count（xuanhuan <=Ch93, all reports） |
|---|---:|
| character_behavior | 537 |
| dialogue_distinctness | 495 |
| world_consistency | 45 |

使用 accepted parent merged report 粗看，问题集中在人物行为与声纹一致性：

| category | count |
|---|---:|
| character_behavior | 82 |
| dialogue_distinctness | 57 |
| world_consistency | 10 |

因此 172b.q 不是“改量具即可过关”，而是：

1. 先把 CED 量具修成“consistency-only、去双计数、可解释”的口径；
2. 再针对人物行为/声纹 consistency 做修复或校准；
3. 最终仍以 sci-fi 同口径 baseline 对标，不放宽 tolerance。

## 4. 初步修复方案

### 4.1 CED 量具修正

新增/固化 CED helper：

- 只计 `severity in {critical, major}` 且有 `evidence_quote` 的 issue。
- 只计 consistency 类别：
  - `character_behavior`
  - `dialogue_distinctness`
  - `world_consistency`
  - `supporting_character_goal_presence`
  - `continuity`
  - `state_mismatch`
  - `setting_conflict`
- 对每个被审版本，优先使用 `audit_type='merged'`，避免 `llm` + `merged` 双计数。
- 对 accepted head，使用 `accepted_version.parent_version_id` 对应的 source merged report；若历史 sci-fi accepted 版本缺 parent，则需要明确 fallback（例如当前 chapter head 的审查源版本或 all-merged 口径），并在 baseline 中同口径重算。

### 4.2 consistency 修复方向

在量具口径稳定后，如果 xuanhuan 仍 FAIL：

1. 解剖 `character_behavior` / `dialogue_distinctness` 的高频角色与证据句；
2. 判断是：
   - xuanhuan 角色声纹确实不稳；
   - LLMAuditor 对短句/口癖等 sci-fi 风格假设过强；
   - 多轮修订导致旧版本问题被过程性放大；
3. 只对真实 consistency 问题做修复：
   - 加强角色声纹卡注入或压缩保真；
   - 修正 LLMAuditor 体裁无关性；
   - 必要时定点重跑高风险章；
4. 不处理 `show_dont_tell` / `narrative_pacing` 等文学 craft 项作为 CED 阻塞门。

## 5. 验收

1. 新 CED helper 有单测覆盖：
   - craft category 不计入 CED；
   - `llm` + `merged` 不双计数；
   - accepted version 通过 `parent_version_id` 找到审查源；
   - scifi fallback 口径可解释。
2. 重算 sci-fi Ch25/50/75/100 baseline，并落盘新 CED 字段或报告。
3. 重算 xuanhuan Ch93 / Ch100：
   - budget / overdue / health / completeness 仍使用既有 vdim 口径；
   - CED 使用修正后的 consistency-only 口径；
   - 若仍 FAIL，进入 4.2 的真实 consistency 修复。
4. 修复后再 resume 172b 到 Ch100；最终 `vdim_compare.py 100` 五门 PASS 才能闭合 V 维度。
