## 关键设计决策（留痕）

1. **历史 NULL 行保守计 halt**：不追溯改写历史 paused 行语义；只有新代码写入的明确 reason 才区分。这保证 xuanhuan Ch200 等历史终判结论零漂移（复跑已实证）。
2. **cost_budget 暂停不是质量 halt**：预算熔断是资源约束、可提额 resume，与质量熔断（health_low 等）分开；five-gate 的 halt 证据只反映质量/失败。
3. **segment_audit 不改比较符**：深入核对后发现 halt 路径（find_orphaned）本就是 `>` 语义，任务书预判的 off-by-one 是对 `_helpers`（不同消费者）的误对齐；保持 `>` 并留注释。
4. **评测侧 DB 覆盖层只读解析**：`_resolve_orphan_thresholds` 不复用 async `load_profile()`（它读环境 DATABASE_URL，会污染口径），在目标库只读连接内复刻 172i 合并语义。
